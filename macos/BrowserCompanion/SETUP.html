Connect your browser

Tabnax reads tab titles and browser tab identities. It never reads page contents, private tabs, history or passwords.

Arc, Chrome, Edge and Brave

Open the browser. In Tabnax → Settings → Browser tabs, choose Set up for that browser and continue to the macOS Automation prompt. Approve access, then open Tabnax with your shortcut and choose Browser tabs.

Zen and Firefox

Choose Set up in Tabnax first. Tabnax registers its native connection for you; no terminal commands or copied configuration files are needed.

Development build: this bundle contains the companion source. A signed add-on has not been published, so permanent installation is not yet available. For local testing, open about:debugging#/runtime/this-firefox in the browser, choose Load Temporary Add-on, and select manifest.json alongside this guide. The browser removes temporary add-ons when it quits.

A distribution build must replace this development step with installation of the Mozilla-signed companion. Never change the browser’s signature-verification preferences.

Safari

Enable the included Tabnax companion in Safari Settings → Extensions. Development builds require Safari’s own approval for an unsigned extension. A signed distribution build must include a signed Safari extension. Private browsing is excluded even if Safari offers an additional private-browsing permission.

Check the connection

The browser row changes to Connected only after a real handshake or successful approved query. Open two normal tabs with the same title, select each through Tabnax, and confirm that the exact tab and window receive focus. Change the range to Active browser window to check filtering. Closing or moving a tab must never give its old label to another live tab.

If the browser is closed, denied access, or disconnected, Tabnax keeps that status visible. Return to Set up or Retry after changing approval. No browser is launched merely by being listed.
