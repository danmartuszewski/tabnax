GOOD TO KNOW

A few little details.

Can I use Tabnax on my Mac?+

Tabnax is a native app for macOS 15 or later on Apple silicon. The current project builds locally with Xcode. A signed public download is not available yet.

How do I open the switcher?+

Hold Command and press Tab, then type a letter while still holding Command. Prefer to keep the macOS app switcher? Switch to Control–Option–Space or record your own shortcut, and choose press-to-open or hold-to-show. In this browser demo, click the desktop and use Space.

What permissions does it need?+

Accessibility lets the native app discover and focus windows and handle its keyboard shortcuts. It does not request Screen Recording or additional Input Monitoring. Browser connections require their own Automation or extension approval. This page only uses sample data.

How do browser connections work?+

Arc, Chrome, Edge and Brave use built-in adapters with browser-specific Automation approval. Firefox and Zen use a companion extension; permanent installation needs a signed add-on. Safari uses its embedded extension with Safari approval. Production signing and browser-store publication are still pending. Private tabs are excluded.

Is this the actual app, or a demo?+

The playground is a browser simulation of the current six layouts and selected features. It cannot switch real windows or launch apps. The settings gallery and “native view” images are actual app-owned renders from the September 20, 2026 reviews. Glass in the playground is a CSS approximation.

Run Tabnax on your Mac.

The native app is ready to build from this project. You’ll need an Apple silicon Mac, macOS 15 or later, and Xcode.

  1. Open this project’s macos folder.
  2. Double-click Run Tabnax.command to build and open the app.
  3. Follow Settings → General to allow Accessibility, then try ⌘ Tab.

Or run this from the project directory:

./macos/scripts/dev.sh

Development build. A signed public download and browser-store releases are not available yet.
