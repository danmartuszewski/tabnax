CHOOSE BY SWITCHING HABIT

Different strengths.
Separate modes.

Shore remains the compact baseline for random window switching. Lattice tests whether learning a spatial address makes selection more natural. Fold trades an extra key for a smaller set of choices. Relay gives repeated back-and-forth work its own interaction.

There is no need to force these into one interface. Compare the situations below, then keep only the modes that reduce hesitation in your own work.
