# Historical layout studies

This preserves the studies for Shore, Beacons, Canopy, Lattice, Fold, and Relay. They use synthetic destinations and do not control macOS. Current behavior is documented in the [app README](../macos/README.md); the product presentation lives in [website/](../website/README.md).

Open [index.html](index.html) with its neighboring CSS/JavaScript, or the bundled [tabnax-gallery.html](tabnax-gallery.html). Rebuild the bundle with `python3 design-exploration/package-standalone.py` from the repository root.
